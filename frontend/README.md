# Student AI Mentor — Frontend Foundation

This directory contains the React, TypeScript, TanStack Router, and TanStack Query frontend for the Student AI Mentor application.

## Stack
- **Framework**: React 18 + Vite
- **Language**: TypeScript (Strict Mode)
- **Styling**: Tailwind CSS + Restrained Drishta Palette (60/30/10 rule)
- **Routing**: TanStack Router
- **State Management**: TanStack Query (Server State) + Zustand (Client UI State)
- **Validation**: Zod
- **Icons**: Lucide React

## Design Palette
- **Primary Dark**: `#07020D` (Navigation, Typography, Major structural elements - 30%)
- **Cream**: `#EEF5DB` (Neutral background surfaces - 60%)
- **Light Blue**: `#B8D8D8` (Interactive accents, selected states - 10%)
- **Steel**: `#7A9E9F` (Secondary text, borders)
- **Stone**: `#5E574D` (Supporting UI, muted elements)
